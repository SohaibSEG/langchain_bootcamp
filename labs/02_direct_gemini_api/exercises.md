# Exercises: Direct Gemini API

Use these exercises to experiment with the direct Gemini script. Keep your changes small and run the script after each change.

## Exercise 1

Change the prompt in `scripts/01_gemini_smoke_test.py` so Gemini returns only one label:

- billing
- account
- technical
- product

## Exercise 2

Ask Gemini to draft a two-sentence response to the customer.

## Exercise 3

Try changing `GEMINI_MODEL` in `.env`. Record whether output speed or wording changes.
