# Exercises: Runnables

Use these exercises to practice the runnable interface before adding models.

## Exercise 1

Create a runnable that converts a ticket subject to lowercase.

## Exercise 2

Create two runnables:

- one that strips whitespace
- one that adds the prefix `"Ticket: "`

Compose them with `|`.

## Exercise 3

Create a runnable that accepts a ticket dictionary and returns the ticket subject.
